# DHC Frontend Project Cost Analysis

Estimating the cost for a contract full-stack web developer to design, build, and deploy a comprehensive, modern healthcare application like `dhc-frontend` to Microsoft Azure depends heavily on the developer's experience, location, and the exact scope of the integration. 

Based on the size of the `dhc-frontend` project (which includes 20+ service pages, provider directories, modern UI/UX, and integrations with systems like Phreesia and NextGen), here is a general breakdown of what you could expect to pay a mid-to-senior US-based contract developer (typically billing **$85 to $150 per hour**):

## Project Phases & Estimates

### 1. Discovery, UI/UX Design, & Architecture
*   **Time Estimate:** 40 - 80 hours
*   **Cost Estimate:** $3,400 – $12,000
*   **Tasks:** Information architecture, wireframing, creating a high-fidelity design system (colors, typography, glassmorphism components), and planning the Next.js/React component structure.

### 2. Frontend Development & Integration
*   **Time Estimate:** 120 - 200 hours
*   **Cost Estimate:** $10,200 – $30,000
*   **Tasks:** Building the 20+ static and dynamic pages (Find a Provider, Patient FAQs, Service Lines), implementing responsive design for mobile, optimizing performance, setting up the Apollo GraphQL client, and handling API integrations for external portals (Phreesia, NextGen).

### 3. Azure Deployment & DevOps Setup
*   **Time Estimate:** 20 - 40 hours
*   **Cost Estimate:** $1,700 – $6,000
*   **Tasks:** Setting up Azure Static Web Apps or Azure App Service, configuring GitHub Actions for CI/CD (Continuous Integration/Continuous Deployment) so that pushes to the `main` branch automatically deploy, configuring custom domains, SSL certificates, and environment variables.

### 4. QA Testing, Security Review, & Launch
*   **Time Estimate:** 30 - 50 hours
*   **Cost Estimate:** $2,550 – $7,500
*   **Tasks:** Cross-browser testing, mobile responsiveness testing, accessibility (ADA compliance) review—which is critical for healthcare—and general bug fixing before the final launch.

---

## Final Estimates

> **Total Estimated Cost:** $17,850 — $55,500
> **Total Estimated Time:** 210 — 370 hours *(~5 to 9 weeks of full-time work)*

## Cost Saving Factors

**Offshore/Nearshore Resources**
If you hire a developer outside the US (e.g., Eastern Europe or Latin America), hourly rates drop to **$40–$70/hr**, which would bring the total project cost down to roughly **$8,500 – $25,000**.

**Current Project Scope Reduction**
Since we have already built a significant portion of the frontend architecture and pages together, a contractor coming in now would mostly be doing the Azure deployment, API hooking, and final polish, which would drastically reduce these costs to just a few thousand dollars.
